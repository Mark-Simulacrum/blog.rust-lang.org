The 1.62.0 pre-release is ready for testing. The release is scheduled for
Saturday July 09. [Release notes can be found here.][relnotes]

You can try it out locally by running:

```plain
RUSTUP_DIST_SERVER=https://dev-static.rust-lang.org rustup update stable
```

The index is <https://dev-static.rust-lang.org/dist/2022-06-07/index.html>. You
can leave feedback on the [internals thread][internals].

The release team is also thinking about changes to our pre-release process:
we'd love your feedback [on this GitHub issue][feedback].
